ZX-PLC

An IEC 61131-3 PLC editor and simulator (IL, LD, FBD) for the ZX Spectrum 128K, in your browser.

The tape loads instantly. Load at real speed (about 3.5 minutes, as on a real Spectrum, with the loading stripes) · instant

Keys

Press a key when the loading screen is complete. Click the emulator first so that it gets the keyboard. An English keyboard layout works best.

Esc or Tabopen / close the menu (BREAK / EDIT)
ShiftCAPS SHIFT
CtrlSYMBOL SHIFT (SS); e.g. Ctrl+U undo, Ctrl+Y redo
Arrows, Backspace, Entercursor keys, DELETE, ENTER
% ! $ ( ) … typed as on a PC keyboard (sent as SS + the Spectrum key); operands are e.g. %IX0.0
lettershotkeys of the menus and elements

Try it: Run > Run runs the demo project; in the simulation the keys 0–7 toggle the inputs. Saving and loading projects does not work in the browser, and the UR-4 interface is not emulated here.

Kempston mouse: switch it on with Options > Mouse. Over the emulator the PC pointer is hidden and the Spectrum arrow follows it; if the arrow lags behind, touch an edge of the screen with it.
